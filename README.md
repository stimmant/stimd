# stimd

I wanted a tool for reviewing AI-generated MD files, and found [MacMD](https://macmdviewer.com), but was dismayed to see a price tag like that on something that was clearly just a few Claude prompts. So I decided to just write the prompts myself. I use this tool primarily to review AI generated markdown docs, but also when editing markdown files manually in vim since I'm not an IDE person. Typically when using this with an AI agent, I'll read the document while at the same time dictating feedback using VoiceInk.

Built with SwiftUI + WebKit. Markdown is parsed natively with
[swift-markdown](https://github.com/swiftlang/swift-markdown) (cmark-gfm), rendered
into a WKWebView with bundled [mermaid](https://mermaid.js.org) and
[highlight.js](https://highlightjs.org). Fully offline — no network access, no
telemetry, no Electron.

## Features

- **GitHub-flavored Markdown** — headings, tables (alignment + zebra striping),
  task lists, strikethrough, blockquotes, inline HTML passthrough
- **Mermaid diagrams** — flowcharts, sequence, state, Gantt, pie, etc. in fenced
  ` ```mermaid ` blocks; themed to match the document theme
- **Syntax highlighting** — dozens of languages via highlight.js, colored per theme
- **8 themes** — Auto (follows system), GitHub Light/Dark, Dracula, Nord,
  Solarized Light/Dark, One Dark — pick in Settings (⌘,)
- **Reading preferences** — content width (Narrow/Medium/Wide/Full) and body
  font (System Sans / Serif / Monospace) in Settings; both apply live
- **Settings utilities** — one-click "Use stimd for Markdown Files" default-app
  button, and a toggle for the command-line tool install
- **Table of contents sidebar** — click a heading to scroll to it; shown/hidden
  state persists across launches
- **Smart titles** — windows are titled by the document's top-level `#` heading
  when it has one (the titlebar proxy icon still points at the real file)
- **Live reload** — edit in any editor (VS Code, Zed, Vim…); the preview updates
  ~50 ms after save, preserving scroll position. Atomic saves handled.
- **QuickLook extension** — press Space on a `.md` file in Finder or Spotlight.
  Full fidelity: mermaid diagrams and syntax highlighting render in the preview.
- **`stimd` CLI** — installed to `~/.local/bin/stimd` on first launch:
  `stimd README.md` opens files; `some-command | stimd` renders stdin
- **Zoom** — pinch, ⌘-scroll, or ⌘+ / ⌘− / ⌘0 (persists across launches)
- **Print / PDF** — ⌘P opens the macOS print dialog (always prints the light
  palette, paginates cleanly); ⇧⌘E exports a one-click PDF of the current theme
- **Relative images** resolve against the document's directory
- Links open in your browser; links to other `.md` files open in new stimd windows

## Build

Requires Xcode 16+ and [xcodegen](https://github.com/yonaskolb/XcodeGen)
(`brew install xcodegen`).

```sh
xcodegen generate
xcodebuild -project stimd.xcodeproj -scheme stimd -configuration Release \
  -derivedDataPath build build
open build/Build/Products/Release/stimd.app Sample/demo.md
```

Or `xcodegen generate && open stimd.xcodeproj` and hit Run.

The app icon is generated by `swift scripts/make_icon.swift` (committed as
`App/Resources/stimd.icns`).

## CLI

The app installs/refreshes a small shell shim at `~/.local/bin/stimd` every launch
(it opens documents via the bundle id, so it keeps working if the app moves).
Make sure `~/.local/bin` is on your `PATH`.

```sh
stimd notes.md plan.md        # open files
claude -p "write a report" | stimd   # render piped output
```

Piped input is spooled to a temp file named after the document's `#` title when
it has one (e.g. `Quarterly Numbers.md`), falling back to `Piped at 11.09 PM.md`.

## Architecture notes

- The main window renders via a WKWebView: one full HTML page with theme CSS,
  highlight.js, and mermaid inlined; subsequent updates (live reload, theme
  changes) go through a small `window.mdv` JS API so scroll position survives.
- The QuickLook extension is **data-based** (`QLPreviewReply` returning HTML).
  QuickLook renders that HTML with its own WebKit and *does* execute JavaScript,
  so diagrams and highlighting work in previews. A WKWebView cannot be hosted
  inside a QuickLook extension — its web content process is killed by the
  extension sandbox — and the extension sandbox also can't read the containing
  app's resources, which is why the JS assets are bundled into both the app and
  the appex.
- Print forces the light palette via `@media print` for readable paper/PDF output.

## QuickLook notes

The extension registers when the app first launches. If Finder previews don't
update immediately, run `qlmanage -r` (and `qlmanage -r cache`) or log out/in.

To make stimd the default for `.md`: right-click a Markdown file → Get Info →
Open with → stimd → Change All.
